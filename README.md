# ARTIFY – Online Art Gallery

React + Vite demo marketplace. Data is stored in browser LocalStorage (no backend).
Login is demo-only and not secure; checkout takes no real payments.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:5173

## Build
```bash
npm run build
npm run preview
```

## LocalStorage keys
artify_users, artify_current_user, artify_artworks, artify_cart, artify_wishlist, artify_orders
